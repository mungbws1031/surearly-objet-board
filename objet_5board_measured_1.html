Surearly Objet V02 (260710) — 5보드 실측 배치도 (v2)

DXF 좌표 그대로 5개 부품 클러스터를 실측 위치·비율로 배치함(1 unit = 1mm). 회로도가 아니라 PADS 배치 좌표 기반이라 이전 회로도 기반 추정과 결과가 다름. 박스 안엔 레퍼런스만 짧게 표기하고, 상세 부품명은 아래 카드에서 확인.
Main(MCU) Power(충전/승압) LCD+BLE Button LED+PD 통합광학

① Main-Board

  • U2 — STM32U599VIT6 (MCU)
  • Y2 — SX-32, 16MHz 메인클럭
  • Y1 — CS-3215, 32.768kHz (RTC용)
  • U4/U5 — MCP79410-ISN(RTC) / M24C32-RMN6TP(EEPROM)
  • U6 — MX25L3273FM2I-08G-TR (QSPI 플래시)
  • U3 — TLV840MADL29DBVR (로컬 LDO)
  • U7 — TLV75733PDBVR (3.3V LDO)
  • BZ1 — LET4020S-03L (부저), J3~J8

② PCB-Board (전원부)

  • U13 — BQ24075RGTR (Li-ion 충전)
  • U14 — TPS27081ADDCR (로드 스위치)
  • U15 — TLV61048DBV (부스트 컨버터)
  • J10 — USB4940, J11 — 배터리(53261-02)
  • SW2, L1(2.2µH), D18(SS34FA)

③ LCD-Board

  • U1 — BLE 모듈 (회로도=BoT-nLE512 / 데이터시트=BoT-nLE521, 불일치 확인 필요)
  • LCD — ZT020Q01, 2.0" TFT 4-wire SPI
  • Q1 — MMBT2222A
  • BD1, R1~R6 — 보호다이오드·지지저항
  • J1/J2 — Main-Board行 FFC

④ Button (패널마운트 추정)

  • SW1 — B3U-1000P (택트 버튼)
  • J14 — 53398-02
  • SW1·J14 좌표가 0.92mm 차이로 사실상 같은 지점 — 독립 PCB가 아니라 와이어로 연결된 패널마운트 스위치일 가능성 높음

⑤ LED-Board (광원+검출 통합)

  • D2~D8 — VLMU1610-365-135 ×7 (365nm UV-LED)
  • U9 — TLC5916IPW (정전류 LED 드라이버)
  • D9~D15 — VEMD2503X01 ×7 (포토다이오드)
  • U8,U10 — OPA4397PWR (1단 TIA, 200KΩF)
  • U11,U12 — OPA4397PWR (2단 게인, 19.1K/1KF)
  • J9 — Main-Board行 FFC
확정(개별 보드 DXF 5개, 26.08.21 재검증): 각 파일이 보드 하나와 정확히 1:1 대응 — 지난번 통합DXF 기반 매핑이 전부 정확했음을 재확인. 크기도 이 소스로 정밀화(LCD 38.1×22.5mm, LED 53.0×26.0mm로 소폭 수정).
신규 발견: Button-Board는 SW1·J14 좌표가 0.92mm 차이로 사실상 한 점 — 별도 리지드 PCB가 아니라 와이어 연결 패널마운트 스위치일 가능성이 높음. 확인 권장.
확정(DXF 실측): 5개 클러스터 bbox·부품 레퍼런스 전부 좌표로 확인. Bottom-side 부품(PART_NAME_04 레이어) 포함해서 재검증함.
확정(거버 4개 카파레이어): 이 보드는 4층 PCB (top / GND plane / VCC plane / bottom).
확정(데이터시트): RTC=MCP79410-ISN, EEPROM=M24C32-RMN6TP, QSPI플래시=MX25L3273FM2I-08G-TR, LCD컨트롤러=ZT020Q01, Y2(메인클럭)=SX-32 16MHz, Y1(RTC클럭)=CS-3215 32.768kHz — 전부 이전엔 "레퍼런스 미확인"이었던 항목.
정정(26.08.21): 이전 '원형/타원형 가능성' 철회 — gerbonara로 fab레이어 Arc 63개 실측한 결과 전부 지름 0.2mm급 초소형 호(텍스트 글자의 둥근 획)로, 보드 외곽선이 될 수 없는 크기였음. 개별 보드 DXF 5개에도 외곽선 레이어는 없었지만, 이 결과로 표준 사각형일 가능성이 원형보다 훨씬 높음. 완전 확정은 거버뷰어로 직접 확인 필요.
확인 필요: BLE 모듈 파트넘버가 회로도(BoT-nLE512)와 데이터시트(BoT-nLE521)에서 다름 — 원본 확인 권장.
추정(여전히 미확인): 커넥터 페어링(어느 J가 어느 J와 연결되는지)은 넷리스트 확인 필요.
